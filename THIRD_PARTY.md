# Third-party software and assets

OmniImage itself is Apache-2.0. It depends on, but does not bundle, the following (installed by pip / your system):

| Component | Use | Licence |
|---|---|---|
| NumPy, SciPy | array math, DSP filters | BSD-3-Clause |
| Pillow | image fallback decoding | HPND |
| OpenCV (opencv-python-headless) | image I/O, filters, video fallback | Apache-2.0 |
| PyYAML | project files | MIT |
| FFmpeg (optional, system binary) | video/audio encoding | LGPL-2.1+ / GPL depending on build; **not** bundled |
| OpenEXR (optional) | compressed EXR | BSD-3-Clause |

**No third-party LUTs, sound samples or footage are bundled.** All 14 look LUTs, 7 sound effects and 7 effects are generated by the code in this repository from node graphs, so they carry this project's licence.

Ideas for future integrations (not included yet; check each licence before adding): OpenColorIO, OpenImageIO, ONNX Runtime models (Real-ESRGAN, RIFE, Segment Anything, Whisper, Demucs), Open Source Color grading LUT packs with permissive licences (for example the CC0 collections), Freesound CC0 samples.
